# Eaglercraft-1.21.11-Server
Eaglercraft 1.21.11 Server with TuffXPlus and all of the Via* plugins. Supports Minecraft 1.5.2-1.21.11.
Forked to include paper.jar and limbo.jar

To start:
type *bash startup.sh* into the terminal and press enter

once the server finishes starting, look below and click on the word ports. 

then, right click the 25567 port, and click copy web address.

change the https:// to a wss:// and then put it into the server ip prompt in eaglercraft (link to join: https://ghost542701937-afk.github.io/Tuff-client-1.12.2/)

*note: when joining, you might have to join, wait for it to crash, then join again*
